# Asset Manifest

## Required external image assets

None for v0.1 redesign.

The design must be implementable with:
- CSS;
- existing Lucide icons;
- user initials;
- existing uploaded meal imagery where already supported.

## Brand mark

Use Lucide `Leaf` or `Sprout` + NutriSnap wordmark.

This avoids:
- hunting for a logo file;
- inconsistent raster sizing;
- licensing ambiguity;
- blocking implementation on graphics.

A later release may replace the icon with a final SVG brand mark.

## Icons

Use Lucide only. Canonical mappings are in `DESIGN_SYSTEM.md`.

## Reference artifact

`reference-dashboard-wireframe.svg` is the deterministic layout blueprint.
It is not production artwork.
It exists so the agent can visually inspect hierarchy without needing external design tools.

## No asset-generation tasks

AGY-Manickam must not spend time generating decorative illustrations, gradients, 3D assets, stock imagery, or AI art for this redesign.

Product data and clarity are the visual focus.
